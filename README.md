# mobile-Addiction-screen-time-analysis
A Data Science and Machine Learning project that analyzes smartphone usage behavior and predicts mobile addiction levels using user activity patterns such as screen time, social media usage, gaming hours, sleep duration, stress level, and notification frequency.
## Features

- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Logistic Regression Model
- Addiction Prediction

1. Data Collection
2. Data Cleaning
3. Feature Encoding
4. Visualization
5. Model Training
6. Prediction
7. Accuracy Evaluation
   ## Model Used

- Logistic Regression

## Key Insights

- Higher screen time increases addiction risk
- Lower sleep duration is linked with addiction
- Social media usage strongly affects addiction behavior
